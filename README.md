# Junior Manual QA Portfolio

## Project

Manual QA portfolio based on the Practice Software Testing demo application.

The project demonstrates practical software testing activities, including:

* Test Planning
* Checklists
* Test Case Design
* Test Execution
* Exploratory Testing
* Bug Reporting
* API Testing
* SQL Testing
* Test Reporting

## Application Under Test

Practice Software Testing / Toolshop

<https://practicesoftwaretesting.com/>

## Tools

* Qase — Test Cases and Test Runs
* Jira — Bug Reports
* Postman — API Testing
* PostgreSQL — Database
* Beekeeper Studio — Database GUI
* GitHub — Portfolio repository
* Markdown — Documentation

## Testing Activities

### Functional Testing

The following application areas were tested:

* Authentication
* Registration
* Products
* Product Search
* Cart
* Checkout

### Test Cases

25 test cases were created in Qase.

Test cases cover:

* Positive scenarios
* Negative scenarios
* Required fields
* Invalid input
* Boundary and validation checks

### Test Execution

One initial Test Run was created in Qase.

Test cases were executed and marked as:

* Passed
* Failed
* Blocked

Actual results are documented in Qase.

### Bug Reporting

Discovered defects were reported in Jira with:

* Summary
* Environment
* Preconditions
* Steps to Reproduce
* Expected Result
* Actual Result
* Priority
* Evidence

### Exploratory Testing

Two exploratory testing sessions were performed.

Each session contains:

* Charter
* Duration
* Environment
* Areas explored
* Findings
* Discovered defects

### API Testing

API testing was performed using Postman.

The Postman collection contains requests for the Practice Software Testing API.

### SQL Testing

SQL practice was performed using a separate educational PostgreSQL database.

The database is not connected to the web application.

The database was created specifically for practicing SQL and database testing.

## Repository Structure


## Conclusion

This portfolio demonstrates practical Junior Manual QA skills, including test design, test execution, defect reporting, exploratory testing, API testing, SQL and test documentation.
