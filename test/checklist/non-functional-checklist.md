# Non-functional Checklist

## UI

* [ ] Text is readable
* [ ] Buttons are visible
* [ ] Inputs are readable
* [ ] Elements do not overlap
* [ ] Images are displayed correctly
* [ ] Error messages are understandable

## Navigation

* [ ] Main navigation works
* [ ] Back navigation works
* [ ] Links lead to the expected pages
* [ ] Browser refresh does not cause obvious problems

## Usability

* [ ] Controls are understandable
* [ ] Labels are clear
* [ ] Validation messages are understandable
* [ ] User can understand what action is required

## Responsive UI

* [ ] Desktop layout
* [ ] Tablet-sized layout
* [ ] Mobile-sized layout
* [ ] No major element overlap
* [ ] No horizontal scrolling where it is not expected

## Performance — Basic Checks

* [ ] Pages load without obvious excessive delay
* [ ] Buttons respond to user actions
* [ ] Application does not visibly freeze
* [ ] Loading indicators work where applicable
